# Мобильное приложение тренировок

Демо Axon: план тренировок, журнал упражнений, таймер, графики прогресса и офлайн-режим.

> Демонстрационный проект портфолио Axon. Статус: планирование. В репозитории пока только описание; перечисленные возможности предстоит реализовать.

## Задача

Помочь пользователю планировать занятия и отслеживать результаты.

## Возможности MVP

- Профиль и библиотека демонстрационных упражнений.
- Планы и расписание тренировок.
- Журнал подходов, повторений и весов.
- Таймер отдыха и локальные напоминания.
- История занятий и графики прогресса.
- Офлайн-запись и синхронизация после подключения.

## Демонстрационный сценарий

Пользователь записывает тренировку без интернета, завершает её и после подключения видит синхронизированную историю.

## Критерии готовности

Офлайн-данные переживают перезапуск. Повтор синхронизации не создаёт дубликаты. Таймер учитывает возвращение из фона. Напоминания отключаются.

- Работает демо с синтетическими данными и понятным входом.
- Основной сценарий проверен; запуск и переменные окружения документированы без секретов.
- Подготовлены скриншоты, короткое видео и кейс для сайта Axon.
- Проект обозначен как демонстрационный, без вымышленных клиентов и результатов.

## Границы первой версии

Демонстрационные планы без медицинских рекомендаций; без носимых устройств, подписок и публикации в магазинах в MVP.

## Какие услуги демонстрирует

Мобильная разработка, локальное хранение, офлайн-режим, синхронизация, визуализация данных.

## Этапы реализации

Рабочий [план реализации](IMPLEMENTATION_PLAN.md) описывает Android и веб, силовые тренировки, интерфейс на русском и английском, открытую регистрацию и письма через Resend.

1. Уточнить сценарии, модель данных и интерфейсы; выбрать стек.
2. Реализовать основной пользовательский путь и управление данными.
3. Добавить интеграции, валидацию, обработку ошибок и проверки доступа.
4. Проверить критерии готовности, наполнить демо и подготовить материалы портфолио.

Предлагаемый стек: TypeScript, React Native / Expo для Android и веба, Fastify и PostgreSQL для API, Resend для подтверждения почты и восстановления доступа. Команды запуска и ссылка на демо будут добавлены по мере реализации.
