# Axon Fitness — спецификация первой версии

## Основной путь

Посетитель выбирает русский или английский язык и запускает изолированное демо либо создаёт аккаунт по email и паролю. После подтверждения почты он выбирает силовой план, начинает тренировку, вводит вес и повторения и отмечает выполненные подходы. Данные сразу сохраняются на устройстве. Интернет требуется для первого входа и отправки изменений, но не для продолжения тренировки. После завершения тренировка появляется в истории и графиках; после синхронизации доступна на втором устройстве.

## Навигация и макеты

Общее оформление: тёмный фон, светлые карточки текста, лаймовый акцент, крупные числовые поля. На широком экране боковая панель, на телефоне нижнее меню. Карточки и таблицы растягиваются по доступной ширине; действия имеют подписи и доступные области касания.

| Экран      | Содержание                                                                    | Главное действие            |
| ---------- | ----------------------------------------------------------------------------- | --------------------------- |
| Вход       | Email, пароль, язык, ссылка восстановления, демонстрационный вход             | Войти / создать аккаунт     |
| Обзор      | Статистика недели, следующий план, последние тренировки, статус синхронизации | Начать / продолжить         |
| Планы      | Список, дни недели, упражнения, редактор                                      | Создать / начать план       |
| Тренировка | Название, упражнения, предыдущие результаты, подходы, заметки, таймер         | Отметить подход / завершить |
| Библиотека | Поиск по названиям, мышцам и оборудованию, описание                           | Добавить упражнение         |
| История    | Даты, длительность, объём, подробности, редактирование                        | Открыть тренировку          |
| Прогресс   | Выбор упражнения, история рабочего веса и объёма                              | Выбрать упражнение          |
| Настройки  | Язык, кг/фунты, часовой пояс, напоминания, аккаунт                            | Сохранить / выйти           |

## Состояния и ошибки

- Загрузка данных, пустая история, нет плана, поиск без результата.
- Работа офлайн, ожидающая отправка, отправка, синхронизировано, конфликт версий.
- Ошибка записи на устройство: действие не считается сохранённым, показан повтор.
- Неверные данные, неподтверждённый email, истёкшая сессия, повторный вход.
- Письмо ожидает отправки, временная недоступность Resend, исчерпанная квота, просроченная или использованная ссылка.
- Выход с неотправленными изменениями: предложить остаться или выйти с сохранением локальной очереди аккаунта.

## Контракты хранения

Синхронизируем агрегаты `plan`, `workout`, `settings`. Подходы и снимки названий упражнений вложены в тренировку. Каждый агрегат имеет владельца, клиентский UUID (настройки — постоянный ключ), серверную версию, номер изменения и данные либо отметку удаления. Клиент хранит записи, очередь, конфликты и курсор в одной атомарной записи аккаунта. Адаптеры IndexedDB и SQLite реализуют одинаковый контракт чтения и транзакционного изменения.

`POST /api/sync/push` принимает идентификатор операции, тип, ID, ожидаемую версию и данные. Повтор операции возвращает ранее сохранённый результат. Несовпадение версии возвращает конфликт и серверную запись. `GET /api/sync/pull?cursor=N` отдаёт изменения аккаунта после курсора. Конфликт разрешается явным выбором локальной или серверной версии.

Начальная библиотека содержит только силовые упражнения; кг — каноническая единица хранения. Демонстрационные данные синтетические и не отправляются в API пользовательских аккаунтов.
